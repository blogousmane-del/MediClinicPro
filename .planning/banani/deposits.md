## Fabrication / scope flags (per project's no-fake-functionality policy)
1. **"Admission bloquée" / "débloquer l'admission" gating** — Banani's mock frames this as blocking hospital admission until a deposit clears. MediClinicPro has **no admission/hospitalization concept anywhere in the schema** (no beds, no inpatient status, appointments are outpatient-only). Building real admission-gating would mean inventing a whole new subsystem, far beyond "add the deposit feature." **Proposal: implement deposits as a real, standalone record-and-track feature (create → held → later resolved as refunded/deducted), without a fake blocking mechanic that doesn't connect to anything.**
2. **Fixed critical-care service catalog with fixed prices** (Chirurgie d'urgence 150 000, Réanimation 80 000, Scanner/IRM 45 000, Transfusion 35 000) — these are Banani's invented figures, not this clinic's real tariffs. **Proposal: free-form line items (description + montant) typed by the secretary, same UX already built for Comptabilité → Nouvelle facture, instead of hardcoding fake prices.**
3. Patient allergy/condition badges ("Hypertension artérielle", "Allergie : AINS") — **these map to real fields** (`patients.antecedents`, `patients.allergies`), so they'll be wired to real data, only shown if actually populated.
4. "Reporter — prise en charge partielle" secondary button — no defined real action, tied to the fictional admission gate. **Proposal: drop it** (no decorative dead buttons, same rule already applied elsewhere this session).

## New DB table
```sql
CREATE TABLE deposits (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  clinic_id BIGINT REFERENCES clinics(id) ON DELETE CASCADE NOT NULL,
  patient_id BIGINT REFERENCES patients(id) ON DELETE CASCADE NOT NULL,
  user_id BIGINT REFERENCES users(id) ON DELETE CASCADE NOT NULL, -- who collected it
  amount REAL NOT NULL,
  payment_method TEXT NOT NULL, -- cash, wave, orange_money, mtn_momo
  reference_number TEXT,
  reason TEXT, -- free-text summary of what it's for
  items JSONB DEFAULT '[]'::jsonb, -- [{ description, cost }] estimated services
  estimated_total REAL DEFAULT 0,
  status TEXT DEFAULT 'held', -- held, refunded, deducted
  resolved_at TIMESTAMPTZ,
  resolved_by BIGINT REFERENCES users(id),
  created_at TIMESTAMPTZ DEFAULT NOW()
);
CREATE INDEX idx_deposits_clinic ON deposits(clinic_id);
```
